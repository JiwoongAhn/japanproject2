## 🎯 커뮤니티 활성화 (콘텐츠성)

### 1. 공강 친구에게 "콕 찌르기" (poke)
- **내용:** 지금 공강(빈 시간)인 친구에게 가볍게 콕 찌르기 알림을 보내는 기능.
- **착수 시점:** **출시 후**, 유저가 어느 정도 모인 다음 콘텐츠로 추가.
- **선행 조건:** ① 친구/팔로우 관계 데이터 ② 시간표 기반 "지금 공강인지" 판정 ③ 푸시 인프라(이미 있음).
- **메모:** 익명 문화 고려 — 실명 노출 없이 가볍게, 스팸 방지(횟수 제한) 필요.

## 🪙 수업 후기 포인트 경제

> 아래 2·3은 하나로 이어지는 시스템. **후기 데이터가 어느 정도 쌓인 뒤** 착수.

### 2. 후기 작성 시 포인트 지급
- **내용:** 수업 후기를 남길 때마다 포인트 적립.
- **착수 시점:** 후기 **데이터가 조금 쌓인 후**(초기엔 열람 잠글 콘텐츠 자체가 없으므로).
- **선행 조건:** 유저별 포인트 잔액 테이블 + 적립 트랜잭션 기록(어뷰징 방지: 중복/삭제 후 재작성 악용 차단).

### 3. 포인트로 다른 사람의 후기 열람
- **내용:** 적립한 포인트를 써야 남의 수업 후기를 볼 수 있는 구조(에브리타임식 기여-열람 게이트).
- **효과:** "먼저 기여해야 본다" → 후기 작성 유도 선순환.
- **선행 조건:** 열람 시 포인트 차감 로직 + 이미 열람한 후기 재열람 무료 처리 + 잔액 부족 시 UX(작성 유도).
- **주의:** 초기 유저 이탈 위험 → 무료 크레딧/초기 완화 정책 검토 필요.
