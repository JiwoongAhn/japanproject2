## 3. 앱 동작에 영향 주는 학교 특성
- **00:00〜06:00 시스템 점검으로 사용 불가** → 그 시간에 열면 에러 화면 대신 안내 문구가 필요
- **브라우저 「戻る」 사용 금지** (UNIPA 공식 주의) → 인앱 브라우저의 뒤로가기가 세션을 깨뜨릴 수 있음
- **스마트폰 대응 메뉴 사용 불가** → 앱 안에서 PC 화면이 그대로 뜬다
- 학외 접속은 인증서버(Basic) 한 번 더 → 쿠키 유지가 되는지 실기 확인 필요
- ユーザー名 = 메일 주소 `@` 앞부분 (학번 아님)
