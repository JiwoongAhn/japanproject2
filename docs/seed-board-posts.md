## 투입 방식 메모

- `posts` INSERT 시 `university = '国士舘大学'` 필수 (RLS 조회조건과 완전일치)
- `is_anonymous = true`, `is_hidden = false`, `like_count = 0`
- 댓글은 `post_comments` — **대댓글(parent) 구조 없음**. 평면 2건이 `匿名1` `匿名2`로 표시됨
- 댓글 `created_at`은 글보다 **뒤**여야 자연스러움
- 이미지는 Storage 버킷 `post-images`에 올린 뒤 public URL을 `image_urls` 배열에 넣음

## 기존 더미 글 3건 (삭제 예정 — 승인 대기)

`学食の新メニュー情報` / `今日の1限休講だった〜` / `線形代数のテスト範囲ってどこまで？`
→ 촬영용으로 만든 빈약한 글. 3건이 같은 시각 생성이라 티가 나고, 질문글에 답이 없어
   "아무도 없는 게시판" 인상을 줌.
